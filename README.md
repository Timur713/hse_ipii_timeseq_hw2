# ДЗ 2. Прогнозирование продаж

Товар: 47566 - PARTY BUNTING, гирлянды из флажков.
На данных из ДЗ 1 сравниваю ETS, ARIMA и CatBoost по дням, неделям и месяцам.
Решение: [hw_2.ipynb](hw_2.ipynb).

## Данные

Источник - [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail).
Использую положительные `Quantity` и счета без C по всем странам.
Возвраты не вычитаю. Дни без покупок заполняю нулями, оптовые пики сохраняю.
После исключения неполных периодов остаются 373 дня, 52 недели и 12 месяцев.

## Эксперименты

- Дневные горизонты: 1, 7, 31, 61; недельные: 1, 4, 8; месячные: 1, 2.
- Последние 61 день, 8 недель и 2 месяца оставлены для теста.
  Короткие горизонты используют первые значения того же прогноза.
- Параметры выбраны по средней MAE на валидации до теста:
  три окна для дней и недель, два для месяцев.
- Проверены параметры моделей, `log1p` и длина обучающей истории.
  После `log1p` прогнозы возвращаются в штуки через `expm1`.
- Базовый прогноз повторяет последнюю неделю для дневных данных
  и последнее значение для недельных и месячных.
- CatBoost прогнозирует по шагам и использует свои прогнозы для будущих лагов.
- Метрики: MAE, RMSE, MASE. Масштаб MASE рассчитан по обучению.
  MAPE не используется из-за нулей. Ошибки в штуках сравниваются внутри одной частоты.

Параметры подбирал в [tune_models.py](tune_models.py).

## Основные выводы

MAE в штуках на максимальном горизонте каждой частоты:

| Частота | Горизонт | Базовый | ETS | ARIMA | CatBoost |
| --- | ---: | ---: | ---: | ---: | ---: |
| Дни | 61 | 22.93 | 23.38 | 23.57 | 18.39 |
| Недели | 8 | 90.50 | 105.05 | 90.50 | 95.08 |
| Месяцы | 2 | 369.00 | 479.19 | 894.70 | 1089.19 |

- На один день ETS немного лучше базового прогноза: MAE 9.86 против 10.00.
- На 7, 31 и 61 день лучше CatBoost: MAE 14.15, 15.02 и 18.39 шт.
  У базового прогноза ошибки 17.57, 19.13 и 22.93 шт. CatBoost лучше и по RMSE.
- Недельная ARIMA(0,1,0) без дрейфа повторяет последнее значение
  и совпадает с базовым прогнозом. Дневная SARIMA сохраняет недельную сезонность.
- По месяцам лучше последнее значение, среди трёх моделей - ETS.
  Для обучения есть только 10 месяцев, для теста - 2, поэтому вывод предварительный.
- Все модели пропустили крупный оптовый заказ 21 ноября.
  Данных о будущих крупных заказах в признаках нет.
- Ошибка не всегда растёт с горизонтом: в расчёт входят другие наблюдения.
  Результат подбора CatBoost зависит от seed, поэтому его преимущество
  стоит проверить на других периодах.
